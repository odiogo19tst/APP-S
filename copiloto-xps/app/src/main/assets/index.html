Controle seu XPS-10

Sliders só preparam valores. Toque em Aplicar para transmitir. Valores iniciais não são uma leitura do teclado.

Cenas de controles

Salva os valores destes controles. Não inclui timbre, split ou parâmetros internos MFX.

Ideias para combinar timbres

Piano + pad: deixe o piano em primeiro plano e o pad com ataque lento. Piano + strings: use strings discretas nos refrões. Órgão: experimente chorus moderado, com pouco reverb.

Os botões ajustam os controles abaixo; escolher timbres e configurar camadas ainda é feito no teclado.

Seu setup

IA dentro do aplicativo

Runtime MediaPipe instalado. Importe um modelo LLM compatível no formato .task, como uma conversão Gemma 3 1B para MediaPipe. Um arquivo GGUF não serve. O modelo não acompanha este APK.

O carregamento inicial pode demorar. Compatibilidade e desempenho precisam ser testados no seu S25.

MIDI + áudio

USB lê notas e transmite os controles selecionados. O microfone ouve o ambiente. O cabo USB do XPS-10 transporta MIDI; o som do teclado continua pelas saídas de áudio para o PA.

O app não lê telas de outros aplicativos, não altera áudio já emitido e não possui sincronização com LouveApp ou Cifra Club.

Privacidade

Processamento local, sem conta e sem envio de áudio à nuvem. Repertório e cenas ficam neste aparelho; exporte para backup.
